# Cookbook

One task per recipe. The listings come from programs the documentation build compiles and runs.

| Recipe | When |
|---|---|
| [Time a region on a GPU](/cookbook/gpu-timing) | a timed region launches asynchronous device work |
| [Find a mismatched tic/toc](/cookbook/misuse) | a timer shows a number you do not trust |
| [A CSV for a scaling study](/cookbook/csv) | a script must read the timings |
| [Size a pool from the budget](/cookbook/pool) | the program allocates most of its memory once |
| [A program that initializes MPI itself](/cookbook/own-mpi) | MPI is started by the program or by another library |
| [Run under Slurm](/cookbook/slurm) | the job has less memory than the node |
| [Build without MPI](/cookbook/serial) | a serial build of an MPI program |
